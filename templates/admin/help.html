Help

Short guides for the things you do most.

{% if perms.attendance.add_attendanceregister %}

Take attendance

  1. Open Attendance in the menu.
  2. Press Take attendance next to your class.
  3. Everyone starts as present. Tap Absent, Late or Excused for the exceptions and add a reason if you like.
  4. Press Save attendance. You can open the same day again to correct it.
{% endif %} {% if perms.grades.view_assessment %}

Enter grades

  1. Open Gradebook and choose the term.
  2. Press Enter grades for your subject. Use Add assessment first for a new quiz, midterm or exam.
  3. Type the scores. Leave a box empty if the student has no score yet. An empty box is not counted as zero.
  4. Press Save grades. The term grade, letter and rank update automatically.
{% endif %} {% if perms.reports.view_reportcomment %}

Report cards

  1. Open Report cards and choose the term.
  2. Press Comments to write the class teacher's and the Principal's comments.
  3. Press Class PDF to print the whole class, or PDF beside one student.
  4. Cards say PROVISIONAL until the Principal locks the term. Print the final copies after that.
{% endif %} {% if perms.people.add_student %}

Add students

  1. Open Students. Use Add student for one, or Import from CSV for many.
  2. For an import, download the template, fill it in and choose Preview only first.
  3. Fix any lines the preview lists, then upload again without the preview box ticked.
{% endif %} {% if perms.academics.change_enrollment %}

End of year

  1. Open Classes and tick the class.
  2. Choose Promote this class to next year, pick the next grade and tick any student who repeats.
  3. Use Graduate for the final grade.
{% endif %}

Your account

  1. Use Change password at the top right whenever you like.
  2. After 5 wrong passwords an account is locked for 15 minutes. Wait, or ask the school administrator.
  3. Press the arrows at the top of the menu to make it narrower.
  4. Use the search box at the top to find a student by name or number.
